**Skills:** Robot Learning, Manipulation, Computer Vision, Planning  
**Technologies:** PyTorch, PyBullet, NeRFs, Blender

Developed a manipulation pipeline that uses neural implicit representations (NeRFs) to model unknown objects and plan grasps without requiring object-specific CAD models. The system learns geometry on-the-fly and feeds it into a physics-based planner to achieve robust grasping.
