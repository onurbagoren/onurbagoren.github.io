**Skills:** Linear Systems, PID Control, Mapping, Planning, Uncertainty-Aware Exploration, Computer Vision  
**Technologies:** ROS, Python, C++, MATLAB, Unity

Designed and implemented an autonomous exploration system for a coaxial helicopter scouting agent in a simulated Martian environment. The system uses uncertainty-aware frontier exploration to efficiently map uncharted terrain, coupled with cascading PID control for stable flight.
