**Skills:** Bayesian Inference, Probabilistic Nonlinear Regression  
**Technologies:** Python, NumPy

Developed a Bayesian inference framework to estimate motion parameters (angular velocity, linear velocity) from event camera data. Event cameras offer microsecond-level temporal resolution, making them ideal for high-speed motion estimation. The probabilistic formulation provides uncertainty quantification alongside parameter estimates.
