Projects

Course and independent projects spanning robotics, computer vision, and machine learning.

  • Uncertainty-Aware Martian Surface Mapping Autonomous exploration for a scouting coaxial helicopter in a simulated Martian environment. Combines PID control, uncertainty-aware frontier exploration, and computer vision. ROS · Python · C++ · MATLAB · Unity
  • Language-Guided Visual Navigation in a NeRF World Navigation agent guided by natural language instructions inside a Neural Radiance Field scene, bridging embodied AI with modern scene representations. PyTorch · LLMs · NeRFs · Blender
  • Arbitrary Object Manipulation via Neural Implicit Representations NeRF-based geometry estimation for model-free robotic grasping — no object-specific CAD models required. PyTorch · PyBullet
  • Underwater State Estimation via Novel Initialization Factor-graph SLAM with improved initialization strategies for more robust convergence in GPS-denied underwater navigation. ROS · GTSAM · C++
  • Neural Radiance Fields from Scratch Full PyTorch implementation of NeRF including positional encoding, hierarchical sampling, and volume rendering, reproducing the original paper's results. Python · PyTorch
  • Motion Estimation for Event Cameras via Bayesian Inference Probabilistic nonlinear regression for high-speed motion parameter estimation from neuromorphic event camera streams. Python · NumPy
  • Autonomous Mobile Robots Full autonomous robot stack: SLAM, A* / RRT path planning, and cascading PID control deployed on real differential-drive hardware. C++ · Python · LCM · Eigen
  • ArmLab: Block Sorting & Stacking with a 5-DoF Arm Forward/inverse kinematics, OpenCV-based block detection, and motion planning for pick-and-place tasks on a physical robotic arm. Python · OpenCV · ROS
